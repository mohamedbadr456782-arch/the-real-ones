THE REAL ONES — حكاية عِشرة

المشروع يحتوي على صفحة رئيسية بخمسة كروت، صور الألبومات، الفيديوهات المخصصة، والرسائل.

التشغيل محليًا:
1) فك ضغط الملف.
2) افتح index.html في متصفح حديث.

النشر على GitHub Pages:
1) أنشئ مستودع GitHub جديد باسم the-real-ones.
2) ارفع index.html ومجلد assets بالكامل إلى جذر المستودع.
3) من Settings > Pages اختر النشر من فرع main ومن مجلد /(root).

مهم جدًا بخصوص الخصوصية:
هذه نسخة واجهة ثابتة للمعاينة. كلمات المرور (تواريخ الميلاد) موجودة داخل JavaScript، وملفات الصور والفيديو موجودة في مجلد assets؛ أي شخص لديه رابط الملفات أو يفحص مصدر الصفحة يمكنه الوصول إليها. لا تنشر صورًا أو فيديوهات خاصة بهذه النسخة على موقع عام. للحماية الحقيقية نحتاج ربطًا بخادم مصادقة وتخزين خاص مثل Supabase Storage مع سياسات وصول، وعدم تضمين كلمات السر داخل الواجهة. تاريخ الميلاد وحده أيضًا ليس كلمة سر قوية.
